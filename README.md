## مدل‌ها و آزمایش‌ها

### 1. CNN Baseline

یک شبکه‌ی عصبی کانولوشنی ساده با سه بلوک اصلی Conv2D، ReLU و MaxPooling پیاده‌سازی شده است.

مشخصات آزمایش:

- Input size: `224 × 224`
- Batch size: `32`
- Epochs: `10`
- Optimizer: `Adam`
- Learning rate: `0.001`
- Loss function: `CrossEntropyLoss`

هدف این مدل ایجاد یک خط پایه برای مقایسه با مدل‌های پیشرفته‌تر است.

### 2. Balanced Sampling

برای بررسی اثر عدم‌توازن کلاس‌ها، یک زیرمجموعه‌ی نامتوازن به‌صورت کنترل‌شده و در حافظه ساخته شده است. سپس توزیع نمونه‌برداری معمولی با `WeightedRandomSampler` مقایسه شده است.

این آزمایش توزیع نمونه‌ها را بررسی می‌کند؛ مقایسه‌ی عملکرد دو مدل آموزش‌دیده در این بخش هنوز انجام نشده است.

### 3. CrossEntropyLoss vs BCEWithLogitsLoss

دو تابع Loss از نظر نحوه‌ی دریافت Label و محاسبه‌ی خطا بررسی شده‌اند.

از آنجا که هر تصویر فقط به یک کلاس از هشت کلاس تعلق دارد، `CrossEntropyLoss` انتخاب اصلی پروژه برای طبقه‌بندی چندکلاسه است.

### 4. Regularization و Learning Rate Scheduler

در یک آزمایش جداگانه، روش‌های زیر استفاده شده‌اند:

- Data Augmentation
- Dropout با نرخ `0.5`
- Weight Decay برابر با `0.0001`
- StepLR با `step_size=3` و `gamma=0.1`

هدف، بررسی عملکرد مدل با تنظیمات متفاوت و کاهش وابستگی بیش از حد به داده‌های آموزش است.

### 5. ResNet18 و Transfer Learning

از معماری ResNet18 با وزن‌های ازپیش‌آموزش‌دیده استفاده شده و لایه‌ی خروجی آن برای هشت کلاس پروژه تنظیم شده است.

وزن‌های آموزش‌دیده‌ی مدل در مسیر زیر ذخیره شده‌اند:

```text
models/resnet18_vehicle.pth
```

آزمایش‌های Feature Extraction و Fine-Tuning باید به‌صورت جداگانه ثبت شوند؛ نتیجه‌ی نهایی آن‌ها در این مستند درج نمی‌شود تا زمانی که اجرا و ارزیابی‌شان تأیید شود.

## نتایج اولیه

| مدل / آزمایش | معیار | نتیجه |
|---|---|---:|
| CNN Baseline | Train Accuracy | 98.52٪ |
| CNN Baseline | Validation Accuracy | 82.75٪ |
| ResNet18 | Train Accuracy | 98.57٪ |
| ResNet18 | Validation Accuracy | 95.75٪ |
| Regularized CNN | Train Accuracy | 78.44٪ |
| Regularized CNN | Validation Accuracy | 78.00٪ |

نتایج فوق مربوط به آزمایش‌های انجام‌شده روی داده‌های فعلی پروژه هستند. به‌دلیل تفاوت تنظیمات آزمایش‌ها، مقایسه‌ی آن‌ها باید با درنظرگرفتن معماری، روش آموزش و تنظیمات هر مدل انجام شود.

نتیجه‌ی ResNet18 روی مجموعه‌ی محلی Validation برابر با 95.75٪ بوده است. این عدد نتیجه‌ی ارزیابی روی Test نهاییِ نگهداری‌شده توسط منتور نیست.
