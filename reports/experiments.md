# ثبت آزمایش‌ها (Experiments)

## آزمایش ۱ — مدل پایه ResNet18

### ۱. مشخصات دیتاست

- نوع مسئله: **Classification**
- تعداد تصاویر آموزش (`Train`): **3919**
- تعداد تصاویر آزمون (`Test`): **400**
- تعداد کلاس‌ها: **8**
- مدل مورد استفاده: **ResNet18**

### ۲. مشخصات مدل

- معماری: **ResNet18**
- نوع شبکه: **CNN**
- مدل از پیش آموزش‌دیده (`Pretrained`): **مشخص نشده**
- لایه خروجی: متناسب با تعداد کلاس‌های دیتاست
- تعداد کلاس‌های خروجی: **8**

### ۳. تنظیمات آموزش

| پارامتر | مقدار |
|---|---:|
| تعداد Epoch | **10** |
| Batch Size | **32** |
| Optimizer | **Adam** |
| Learning Rate | **0.001** |
| Loss Function | **ثبت نشده** |
| Scheduler | **استفاده نشده / ثبت نشده** |
| Weight Decay | **ثبت نشده** |
| Momentum | **ثبت نشده** |

### ۴. روند آموزش

مدل **ResNet18** به مدت **10 Epoch** روی مجموعه داده‌های آموزش (`Train`) آموزش داده شد.

در هر Epoch، تصاویر آموزشی به صورت Batchهای **32تایی** وارد شبکه شدند و وزن‌های مدل با استفاده از **Adam Optimizer** به‌روزرسانی شدند.

مقدار اولیه `Learning Rate` برابر با **0.001** در نظر گرفته شد.

پس از پایان فرآیند آموزش، مدل روی مجموعه داده‌ی `Test` ارزیابی شد تا میزان توانایی مدل در تعمیم به تصاویر دیده‌نشده بررسی شود.

### ۵. نتایج آموزش

- **Train Accuracy:** `98.57%`
- **Test Accuracy:** `95.75%`

اختلاف بین دقت آموزش و آزمون:

```text
98.57% - 95.75% = 2.82%
```

بنابراین فاصله‌ی عملکرد مدل روی داده‌های آموزش و آزمون برابر با **2.82 درصد** است.

### ۶. نتایج ارزیابی

| معیار | مقدار |
|---|---:|
| Accuracy | **95.75%** |
| Macro Precision | **0.96** |
| Macro Recall | **0.96** |
| Macro F1-score | **0.96** |

### ۷. تحلیل نتایج

مدل ResNet18 توانست پس از 10 Epoch به دقت **98.57%** روی داده‌های آموزش و **95.75%** روی داده‌های آزمون برسد.

اختلاف **2.82 درصدی** بین عملکرد آموزش و آزمون نشان می‌دهد که مدل روی داده‌های آموزشی عملکرد بالاتری دارد، اما عملکرد آن روی داده‌های آزمون نیز همچنان مناسب است.

مقادیر یکسان **Macro Precision، Macro Recall و Macro F1-score** برابر با `0.96` نیز نشان‌دهنده‌ی عملکرد کلی مناسب و نسبتاً متعادل مدل در میان کلاس‌های مختلف است.

### ۸. جمع‌بندی آزمایش

این آزمایش به عنوان **Baseline Experiment** پروژه در نظر گرفته می‌شود.

نتیجه‌ی اصلی این آزمایش:

> **ResNet18 با تنظیمات اولیه توانست به Test Accuracy برابر با 95.75% و Macro F1-score برابر با 0.96 دست پیدا کند.**

این نتیجه به عنوان معیار پایه برای مقایسه‌ی آزمایش‌های بعدی استفاده خواهد شد.
